Read before you touch the machine

Do not configure BusterPhone on this machine while the primary Mac is running. Both drains poll the same Supabase project, and the drain deletes a row from the relay as its acknowledgement. Whichever machine wins permanently takes the event; the other never sees it, with no error on either side. A real voicemail simply never arrives.

The default costs nothing: enter no Twilio or Supabase credentials here. Onboarding never asks for them. If you want to walk the credential path anyway, set BUSTER_CLAW_TELEPHONY_DRAIN=false — and note that an unset variable means enabled, so the disable must be explicit.
